# NORMEX data packs

- `synthetic/` contains clearly labelled synthetic demonstration datasets.
- `samples/` contains realistic text-only procurement documents that can be uploaded through the UI.
- The bundled application also seeds the SQLite database with authority-curated BIS metadata plus synthetic demo records.
- Authority-curated records are metadata/index records, not copies of BIS standards. Users must verify the controlling BIS publication, amendments, certification/QCO status and current applicability before real procurement.
